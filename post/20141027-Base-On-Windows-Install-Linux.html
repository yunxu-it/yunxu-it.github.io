已有Windows安装Linux双系统

Oct 27, 2014

这周Linux操作系统课程开始了，老师让我们都安装Linux，因为我现在一直在用Linux系统，用的还算熟练，今天刚好帮一个同学转系统，我就顺便写个安装教程

教程以Ubuntu kylin为例，本来我是想推荐我用的Linux Mint，但是Mint初期配置有点麻烦)

开辟空闲分区

因为linux和windows并不是相同的文件系统格式，所以需要给linux分出空闲分区

  • 在windows下，右键计算机-管理-磁盘管理
  • 选择你空闲空间还多的盘，右键-压缩卷
  • 初次使用者可以少压缩点空间出来(一般初期30G左右就差不多了，我现在是把Linux作为主系统，所以分了60G给它，我之前直接装了个32位的在16G的U盘里)

U盘制作Linux启动盘

相信装过windows的同学都知道怎么制作U盘启动盘，不过我还是顺便提一下。
​
制作材料：

  • 大白菜u盘启动盘制作工具
  • ubuntu kylin系统镜像文件

准备完毕，可以开始制作启动盘了。

  1. 安装大白菜（这个应该都会吧，这都不会，后面就不用看了）
  2. 打开,选择ISO模式
  3. 点击浏览，选择到镜像文件
  4. 一键制作USB启动器
  5. 选择启动到U盘，格式化，写入（其实似乎不用选择格式化，写入之前会自动格式化）
  6. 等它完成，会有个测试，点取消，直接重启
  7. 在启动前进入BIOS，修改为U盘优先启动（这个我未截图，百度一下，你就知道）

安装Ubuntu kylin

  • u盘启动后会进入Ubuntu安装界面，如下,选择安装（对于左边的语言，熟悉系统的话，我建议使用英语，因为很多时候命令行用中文很麻烦）
  • 建议此时不要连wifi，这样会安装很慢，更新可以安装完了再下
  • 继续
  • 到了下面这样，选择其他选项

之前有位同学要我帮忙安装linux mint，在我不注意的时候，直接点继续，然后……他的硬盘上只有linux了，所以，要慎重

  • 接下来，给linux分区
    • 点击空闲分区
    • 设置挂载点为/boot，大小为512MB，设置为逻辑分区吧，有的电脑windows分区不同，要是这里设置为主分区，会让后面的linux分区不可用（与图不同）
    • 设置大小为2G，逻辑分区，用于交换空间（其他的都是ext4文件系统），这个交换空间好像就是虚拟内存。
    • 后面设置挂载点为/，大小为15G左右（我这是总60G的分区大小，30G的就分10G就很多了）
    • 最后设置挂载点为/home(就是用户目录)，把剩下的空间都给它，它用的最多
  • 点击现在安装
  • 设置键盘啥的，选汉语
  • 用户名自己填，登陆用的
  • 密码也是，不过最好不要太长，经常要用，不嫌累的随便
  • 确定
  • 安装完成，重启
