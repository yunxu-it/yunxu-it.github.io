2017跨年总结

Jan 1, 2018

昨晚有点微醺，总结又拖延到今天才写。

查了下2017的所作所为，发现技能点点偏了。我的主业似乎没干出啥可道之处，对做菜倒是饶有兴趣。

总结下来，也就几点：

程序员方面：

  1. 写了两个未上线的残缺的个人 App，不足道
  2. 接触了部分Machine Learning，半知半解
  3. 在项目中使用的 React Native，似乎有点意思
  4. 建了个个人公众号，更新频率和博客一样慢🤣

兼职厨师方面：

  1. 就那样。。。。
  2. 买了两样好用的工具
  3. 回锅肉和番茄炒蛋还是那么难控制

其他：

  1. 养了头小黄猪
  2. 剁手了台黑卡，希望能提高摄影技术吧
  3. 修理厨房卫浴，更换 iPhone手机电池😌

2018总得有点目标吧

  1. 上线一个持续更新的个人 App，向大佬学习
  2. 入门 Machine Learning，更新自己
  3. 学点设计，给自己画个 Logo
  4. 夯实基础，持续更新博客+公众号（后半句有点难😌）
  5. 把回锅肉和番茄炒蛋做好
  6. 周末摆摊修手机贴膜
  7. 改掉拖延症。。。
  8. 还有其他那啥

附录

虽然今年我做的东西不多，用的好工具不少，可推荐大家使用

APP：

  • iOS：
    • 微信读书（读书可挣书币买书，有好友阅读排行激励，我已经坚持看了好多本了）
    • Diary，Zine（都是可以拿来写小段文字的，喜欢他们的格式）
    • 鲨鱼记账 Pro（用过很多记账工具，唯有这个深得我心，另外，我的 Android 版记账工具正在开发😁）
    • MindNode（思维导图工具，因为颜值高，但是有点贵，iOS 可以等限免或降价）
  • Android：
    • 纯纯写作（写作工具，移动端比较好用的工具之一，收费，不贵）

生活：

  • 菜刀推荐邓家刀，物美价廉，削铁如泥
  • 中式熟铁炒锅推荐陈枝计，同样物美价廉，适合喜欢做中餐的人
  • 电动牙刷，适合懒得动手的懒人
  • 吸尘器，减负生活的好帮手，特别是养猫的人
  • 忠告：不是特别有闲心的人，别买烤箱！别买烤箱！！别买烤箱！！！

新年快乐👏
