墨览 · MarkView 隐私政策

生效日期：2026-10-13

适用版本：1.2.0

本地文档处理

墨览用于预览您在 Chrome 中主动打开、选择或拖入的 Markdown 文件，以及浏览您主动选择并授权的文件夹中的 Markdown。文件内容、文件名和路径仅用于本地渲染、标题展示、章节定位、文件树导航、关联当前文档，以及解析图片和链接。我们不会将这些文档信息上传到开发者服务器。

扩展不会全盘扫描或自动访问未经您授权的其他目录。文件夹访问只请求读取权限，用于枚举所选目录及子目录、打开您点击的 Markdown；为关联已有文档，必要时读取名称唯一匹配的候选正文进行比对。再次打开页面时，若已记住目录且读取权限仍有效，会重新枚举该授权目录；权限失效时，需要您点击继续读取才能申请授权。直接预览 file:// 文档需要您在扩展详情中开启“允许访问文件网址”。

数据收集与存储

当前版本不包含账号登录、广告、分析统计或遥测服务。扩展在用户设备上读取和渲染用户主动打开的文档，并保存阅读记录，用于恢复阅读位置。开发者不会接收这些文档或阅读记录，也不会将其出售、上传或用于广告分析、模型训练。文档中的远程图片请求见下文“图片与外部链接”。

扩展没有自己的云端存储，不持久保存文档正文或文件列表。选择、拖入的文档及已枚举文件列表只保留在当前页面内存中。刷新后，单文件需要重新打开；文件树可在已有授权有效时通过保存的目录句柄恢复。Chrome 自身的历史记录、缓存及其他浏览器行为由浏览器设置与政策管理。

扩展使用 chrome.storage.local 在本机保存侧栏宽度、展开/收起状态和阅读位置。文档地址，或主动选择、拖入文件的文件名与内容，以及目录文档的相对路径与内容，仅在本机生成 SHA-256 标识。阅读记录保存此标识、滚动数值和最近使用时间，不保存原始路径、文件名或正文；最多保留最近使用的 200 份文档，超出时自动清理最久未使用的记录。这些数据不会上传或跨设备同步。

原生只读目录模式在当前页面来源的本地 IndexedDB（markview-folders）保存最近一次成功打开的目录句柄，可通过该句柄取得目录名称并在已有读取权限有效时恢复访问。此记录不保存完整磁盘路径、文档正文或文件列表，不上传、不跨设备同步；一直保留到您选择其他目录替换、使用“打开 → 忘记文件夹”删除，或清除对应浏览器本地数据。兼容文件夹选择方式只在当前页面保留文件对象，不保存目录句柄。

图片与外部链接

Markdown 中的远程图片可能由浏览器向图片所属网站发起请求。对方可能获得 IP 地址和浏览器自动发送的请求信息；这些请求不经过开发者服务器，适用图片网站自身的隐私政策。点击外部链接会打开对应网站。

直接打开本地 Markdown 时，相对路径图片和链接由浏览器按原文件位置解析；选择文件、文件夹及拖拽模式无法取得完整磁盘路径，因此不支持相对图片和跨文档相对链接解析。

权限与选择

文件网址访问仅用于预览用户主动打开且匹配后缀的 Markdown；文件夹读取仅限您选择并授权的目录。阅读记录只用于本地阅读恢复，扩展不读取或汇总普通网站的浏览历史。

您可以通过“打开 → 忘记文件夹”删除目录记忆和当前文件树，这不会删除磁盘文件，也不代替 Chrome 的授权撤销。您可以在浏览器权限设置中撤销文件夹访问，在浏览器设置中清除对应页面来源的本地数据，或在扩展详情中关闭文件网址访问、禁用或卸载扩展。关闭预览页面会结束该页面内的文档处理，已保存的阅读记录及目录句柄仍按上述规则管理。

变更与联系

如果后续版本加入广告、账号或新的数据处理功能，我们会更新本政策，并按适用要求提供说明及取得必要同意。当前政策不涵盖尚未发布的功能。
