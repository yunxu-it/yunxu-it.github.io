墨览 · MarkView 隐私政策

生效日期：2026-10-04

适用版本：1.1.0

本地文档处理

墨览用于预览您在 Chrome 中主动打开或拖入的 Markdown 文件。文件内容、文件名和本地路径仅用于当前浏览器中的渲染、标题展示、章节定位，以及解析图片和链接。我们不会将这些文档信息上传到开发者服务器。

扩展不会扫描您的磁盘或自动读取其他文件。直接预览 file:// 文档需要您在 Chrome 扩展详情中主动开启“允许访问文件网址”。

数据收集与存储

当前版本不包含账号登录、广告、分析统计或遥测服务。扩展在用户设备上读取和渲染用户主动打开的文档，并保存阅读记录，用于恢复阅读位置。开发者不会接收这些文档或阅读记录，也不会将其出售、上传或用于广告分析、模型训练。文档中的远程图片请求见下文“图片与外部链接”。

扩展没有自己的云端存储，不使用扩展存储接口保存文档。拖入的文件仅保留在当前页面的内存中，刷新后需要重新拖入。Chrome 自身的历史记录、缓存及其他浏览器行为由浏览器设置与政策管理。

扩展在本机保存侧栏宽度和阅读位置。文档地址，或主动选择、拖入文件的文件名与内容，仅在本机生成 SHA-256 标识；扩展存储中保存此标识、滚动数值和最近使用时间，不保存原始路径、文件名或文档内容。阅读位置最多保留最近使用的 200 份文档，超出时自动清理最久未使用的记录。这些记录不会上传或跨设备同步。

图片与外部链接

Markdown 中的远程图片可能由浏览器向图片所属网站发起请求。对方可能获得 IP 地址和浏览器自动发送的请求信息；这些请求不经过开发者服务器，适用图片网站自身的隐私政策。点击外部链接会打开对应网站。

直接打开本地 Markdown 时，相对路径图片由浏览器按原文件位置解析；拖拽模式无法取得原始目录，因此不支持同目录图片解析。

权限与选择

本地文件访问仅用于预览用户主动打开且匹配后缀的 Markdown 文档；阅读记录仅用于本地阅读位置恢复，不读取或汇总普通网站的浏览历史。您可以在扩展详情中关闭文件网址访问、禁用或卸载扩展。关闭预览页面即可结束该页面内的文档处理，已保存的本地阅读记录仍按上述保留规则管理。

变更与联系

如果后续版本加入广告、账号或新的数据处理功能，我们会更新本政策，并按适用要求提供说明及取得必要同意。当前政策不涵盖尚未发布的功能。
